# 通路管理系統部署檢查清單

## 部署前檢查清單

### 1. 系統需求確認

- [ ] **硬體需求**
  - [ ] CPU: 4 核心以上
  - [ ] 記憶體: 8GB 以上
  - [ ] 硬碟: 50GB 以上可用空間
  - [ ] 網路: 穩定的網際網路連線

- [ ] **軟體需求**
  - [ ] Docker 20.10+ 已安裝
  - [ ] Docker Compose 2.0+ 已安裝
  - [ ] Git 2.30+ 已安裝
  - [ ] 防火牆配置正確（開放 80, 443 埠）

### 2. 環境配置

- [ ] **環境檔案**
  - [ ] `.env` 檔案已從 `.env.example` 複製
  - [ ] `APP_ENV` 設定為 `production`
  - [ ] `APP_DEBUG` 設定為 `false`
  - [ ] `APP_KEY` 已生成
  - [ ] `APP_URL` 設定正確

- [ ] **資料庫配置**
  - [ ] `DB_CONNECTION` 設定為 `mysql`
  - [ ] `DB_HOST`, `DB_PORT`, `DB_DATABASE` 設定正確
  - [ ] `DB_USERNAME`, `DB_PASSWORD` 設定安全密碼
  - [ ] 資料庫連線測試通過

- [ ] **Redis 配置**
  - [ ] `REDIS_HOST`, `REDIS_PORT` 設定正確
  - [ ] `REDIS_PASSWORD` 設定安全密碼
  - [ ] Redis 連線測試通過

- [ ] **郵件配置**
  - [ ] `MAIL_MAILER`, `MAIL_HOST` 設定正確
  - [ ] `MAIL_USERNAME`, `MAIL_PASSWORD` 設定正確
  - [ ] 郵件發送測試通過

### 3. 安全配置

- [ ] **SSL/TLS**
  - [ ] SSL 憑證已安裝
  - [ ] HTTPS 重定向已設定
  - [ ] SSL 配置測試通過

- [ ] **防火牆**
  - [ ] 只開放必要埠號 (22, 80, 443)
  - [ ] 資料庫埠 (3306) 僅內部存取
  - [ ] Redis 埠 (6379) 僅內部存取

- [ ] **檔案權限**
  - [ ] `storage/` 目錄權限設定為 775
  - [ ] `bootstrap/cache/` 目錄權限設定為 775
  - [ ] 其他敏感檔案權限設定正確

### 4. 程式碼部署

- [ ] **原始碼**
  - [ ] 程式碼已從 Git 倉庫拉取
  - [ ] 切換到正確的分支 (main/production)
  - [ ] 程式碼版本確認正確

- [ ] **依賴安裝**
  - [ ] Composer 依賴已安裝 (`composer install --no-dev`)
  - [ ] NPM 依賴已安裝 (`npm install`)
  - [ ] 前端資源已編譯 (`npm run build`)
